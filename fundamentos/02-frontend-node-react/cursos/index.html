    Cursos — frontend, Node y React¶

    El orden de esta carpeta manda más que el orden de cualquier curso. Un curso de React visto antes del ejercicio 2 se olvida encima de un JavaScript flojo.

    Gratuitos¶

    MDN, Learn web development¶

    • https://developer.mozilla.org/en-US/docs/Learn_web_development
    • HTML, CSS y JavaScript con la calidad de la referencia del navegador. Haz los módulos que fallen en los ejercicios 1 y 2, no el sitio entero “por si acaso”.

    javascript.info¶

    • https://javascript.info/
    • El mejor texto gratuito de JavaScript. Parte 1 (el lenguaje) y la sección del documento (DOM y eventos) cubren el ejercicio del carrito. La parte de red cubre fetch.

    The Odin Project (Full Stack JavaScript)¶

    • https://www.theodinproject.com/paths/full-stack-javascript
    • Currículo largo, proyectos y comunidad. Gratis. Si solo quieres recordar, salta a los cursos de JavaScript, Node y React de ese camino en lugar de rehacer Foundations desde cero.
    • React, dentro del mismo proyecto: entra desde el camino anterior cuando termines su JavaScript. La introducción del curso de React insiste en eso, con razón.

    React, documentación oficial¶

    • https://react.dev/learn
    • Quick Start y el tutorial del tres en raya. Es la fuente que debes seguir cuando un vídeo de 2021 hable de clases. Los ejercicios 5 a 7 están pensados para componentes función y hooks.

    Node.js, Learn¶

    • https://nodejs.org/en/learn
    • Introducción oficial, corta. Léela antes del ejercicio 3 para recordar qué es el entorno y qué módulos trae (node:http, node:fs).

    Eloquent JavaScript¶

    • https://eloquentjavascript.net/
    • Libro gratuito. Úsalo si javascript.info se te queda corto en el lenguaje y quieres ejercicios de programación, no de navegador.

    CSS en la práctica¶

    • Flexbox Froggy: https://flexboxfroggy.com/
    • Grid Garden: https://cssgridgarden.com/
    • Guía de Flexbox: https://css-tricks.com/snippets/css/a-guide-to-flexbox/
    • Learn CSS: https://web.dev/learn/css
    • Juegos de una hora. La guía de CSS-Tricks es la chuleta cuando el layout se rompe.

    Frontend Mentor¶

    • https://www.frontendmentor.io/challenges
    • Diseños reales para maquetar. Cuando cierres el ejercicio 1, elige un reto “newbie” y compáralo con el tuyo. No mires la solución del reto el primer día.

    Exercism, JavaScript¶

    • https://exercism.org/tracks/javascript
    • Ejercicios pequeños del lenguaje, con mentoría. Sirve entre el ejercicio 2 y React, para no oxidar arrays y funciones.

    freeCodeCamp, JavaScript¶

    • https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/
    • Certificado gratuito. Útil si prefieres lecciones muy guiadas a leer javascript.info. El de bibliotecas de frontend del mismo sitio existe; hazlo solo si la documentación de React no te encaja.

    Scrimba, Learn React¶

    • https://scrimba.com/learn-react-c0e
    • Curso interactivo y gratuito (Bob Ziroll, React actual). Buen segundo pase si el Quick Start oficial se te hace árido. El resto del catálogo de Scrimba es de pago: para este repaso basta el curso de introducción.

    De pago¶

    The Complete JavaScript Course (Jonas Schmedtmann, Udemy)¶

    • https://www.udemy.com/course/the-complete-javascript-course/
    • Muy completo, orientado a proyectos. Págala si quieres un solo vídeo que cubra lenguaje, DOM y herramientas modernas, y no vas a leer javascript.info.

    The Ultimate React Course (Jonas Schmedtmann, Udemy)¶

    • https://www.udemy.com/course/the-ultimate-react-course/
    • React actual, con proyectos. Tiene sentido después del ejercicio 5, no antes. Ignora las secciones de un framework full stack hasta que el ejercicio 8 esté cerrado.

    Frontend Masters¶

    • https://frontendmasters.com/
    • Suscripción. Cursos cortos de gente que mantiene librerías. Busca “Complete Intro to React” y un intro de Node cuando quieras una segunda explicación de pago, más densa que Udemy.

    Epic React (Kent C. Dodds)¶

    • https://www.epicreact.dev/
    • De pago, talleres. Para cuando ya haces componentes y quieres entender render, efectos y composición con más precisión. No es un curso de “primera semana”.

    Qué dejar para más adelante¶

    Meta-frameworks (Next.js y similares), gestión de estado global, TypeScript estricto y tests de componente. Entran bien después del proyecto de esta carpeta, no como sustituto de los ocho ejercicios.
