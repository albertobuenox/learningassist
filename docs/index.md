# Learning Assisted

Material de estudio para recuperar el oficio: fundamentos de desarrollo, uso de agentes con criterio, y el vocabulario con el que se habla en el equipo y en una entrevista.

## Por dónde empezar

1. **[Fundamentos](fundamentos/README.md)** — Asignaturas con glosario, cursos y enunciados. Empieza por Git el primer día; el resto sigue el orden de la tabla del README.
2. **[Agentes](agentes/README.md)** — Lecciones para usar Claude o Cursor sin soltar el criterio. Mejor sobre un ejercicio ya cerrado de fundamentos.
3. **[Compendio](compendio/README.md)** — Términos y frases del entorno laboral y de entrevista.

## Cómo estudiar aquí

Lee poco, practica pronto. Cada enunciado pide un resultado observable y una forma de saber si está bien. Las soluciones no están escritas a propósito.

Si usas un agente, las lecciones de **Agentes** van después de haber cerrado al menos un ejercicio a mano.
