# Compendio del oficio

Vocabulario que un desarrollador usa con el equipo, con producto y en una entrevista. Está fuera de `fundamentos`: allí se practica el oficio; aquí se reconoce el lenguaje con el que se habla de él.

## Cómo usarlo

1. Lee un bloque de [términos](terminos.md). No los memorices en lista.
2. Busca esos términos dentro de una frase de [entorno laboral](frases-trabajo.md). La frase es el contexto: standup, revisión, incidente, despliegue.
3. Lee [entrevista](frases-entrevista.md) cuando quieras oír el mismo vocabulario contado a alguien que no vio el ticket.
4. Cierra cada bloque con una frase tuya, sobre un trabajo real o sobre un ejercicio de `fundamentos`. Si no puedes colocar el término en una situación, todavía no es tuyo.

Las frases mezclan español y los anglicismos que se oyen en un equipo (PR, deploy, staging, rollback). En una entrevista puedes decir el término en inglés y explicar en español qué decidiste con él.
