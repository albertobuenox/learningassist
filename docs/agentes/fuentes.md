# Fuentes

Léelas en el punto que indica cada lección. No hace falta un curso de pago para cerrar las once.

## El oficio, en este orden

### Building effective agents (Anthropic)

- https://www.anthropic.com/engineering/building-effective-agents
- El texto de referencia: un agente es un modelo con herramientas en un bucle, y el bucle simple gana a un enjambre. Léelo entero antes de la lección 10, no el primer día.

### Best practices, Claude Code

- https://code.claude.com/docs/en/best-practices
- Cómo encargar, cómo verificar, cómo no hinchar las instrucciones. Es la fuente de las lecciones 2, 6 y 7 aunque uses Cursor: el criterio se traslada.

### Cómo recuerda el proyecto

- https://code.claude.com/docs/en/claude-md
- `CLAUDE.md`, qué entra, el tope orientativo de 200 líneas, y por qué una regla larga se ignora. Lección 7.

### Overview de Claude Code

- https://code.claude.com/docs/en/
- Para situar terminal, IDE y permisos si aún no has instalado Claude Code. No sustituye a las prácticas.

## Prompt, cuando el chat no edita

### Prompt engineering overview

- https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
- Empieza por el criterio de éxito y una forma de comprobarlo. Sin eso, retocar el prompt es decorar.

### Prompting best practices

- https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices
- La referencia viva de Claude. Úsala cuando una respuesta del chat sea vaga: estructura, ejemplos, y no pedir el proyecto entero en un mensaje.

## Cursor, los mismos hábitos con otros nombres

### Agent

- https://cursor.com/help/ai-features/agent
- Agent edita. Ask no. Plan revisa el enfoque antes. Debug cuando hace falta evidencia de ejecución.

### Plan mode

- https://cursor.com/docs/agent/plan-mode
- Lección 5. Si el plan salió torcido, se corrige el plan y se rehace, en vez de apilar parches.

### Rules

- https://cursor.com/docs/rules
- El equivalente de proyecto a `CLAUDE.md`. También `AGENTS.md` cuando basta un markdown.

### Skills

- https://cursor.com/docs/skills
- Procedimientos que se invocan, no texto presente en cada turno.

### Prompting agents

- https://cursor.com/docs/agent/prompting
- Qué entra en el prompt del agente (reglas, skills, herramientas, conversación resumida) y cómo cambiar de modelo a mitad.

## Qué dejar fuera

Cursos que venden “el prompt definitivo” o listas de trucos para saltarse instrucciones. El modelo cambia; el bucle y el diff no. Un prompt que pide ignorar reglas no es una técnica de este recorrido.
