# Claude y agentes

Lecciones para usar Claude, y un agente que edita código, sin soltar el criterio. No es una asignatura de `fundamentos/`. El producto sigue siendo tuyo: el agente propone diffs, comandos y planes.

Sirve igual en tres sitios. Las palabras cambian; el bucle no.

| Sitio | Qué es |
| --- | --- |
| Claude, en el chat | Responde. No toca tus archivos. Tú pegas el contexto y aplicas el cambio. |
| Claude Code | Agente en la terminal o en el IDE. Lee el repo, edita y ejecuta, con permisos. |
| Cursor, modo Agent | El mismo tipo de bucle, con reglas, Plan y Ask. |

Haz las lecciones en un repositorio de práctica, no encima de un encargo con prisa. Un ejercicio ya cerrado de `fundamentos/` vale como víctima.

## Cómo cerrar una lección

Respondes las preguntas del final sin mirar el resumen que escribió el agente. Si la respuesta es “porque lo dijo Claude”, la lección no está cerrada.
