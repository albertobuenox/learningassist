# 07 — Una prueba de cinco minutos

!!! info "Antes de empezar"

    Tiempo: preparar 45 minutos, probar 15, anotar 30. Hace falta otra persona. No hace falta que sepa de clínicas ni de diseño.

??? tip "Pista"

    Si te atascas, abre el [glosario](../glosario.md) de la asignatura y el README antes de un curso largo. Una sola entrada suele desbloquear el enunciado.

## Prototipo

Enlaza en Figma (o en papel, señalando con el dedo) el camino del ejercicio 2:

- abrir el día;
- ver que el jueves no tiene hueco a media mañana;
- pasar al viernes;
- reservar;
- ver la confirmación con hora y nombre.

Incluye un callejón: un botón que parezca confirmar y todavía no lo haga, o el hueco ocupado. Quieres ver si se confunde, no lucir el caso feliz.

## La prueba

Le das un fin, en voz alta: “Reserva a Ana Ruiz con la doctora Soler, el jueves por la mañana; si no hay sitio, el viernes. Dime cuando creas que ya está reservada.”

No señales. No expliques la interfaz. Si se atasca más de un minuto, anota dónde y solo entonces da una pista. Una persona basta para este ejercicio; si puedes repetir con una segunda, mejor.

## Qué entregar

- La tarea, escrita tal como se la dijiste.
- Cinco observaciones como máximo, cada una con lo que **hizo** (no lo que crees que pensó).
- Un cambio concreto que harías en el prototipo a raíz de una observación. El cambio se aplica. La versión anterior se conserva al lado, para ver la diferencia.

!!! success "Cómo sabes que está bien"

    - Tus notas no dicen “le gustó” ni “estaba confusa”. Dicen “pulsó Borrar creyendo que volvía atrás” o “no encontró el viernes”.
    - El cambio que aplicaste responde a una de esas frases, no a un gusto tuyo que apareció durante la prueba.
    - Si nadie se equivocó, o la tarea era demasiado guiada o el prototipo solo tenía un botón. Añade el callejón y repite.
