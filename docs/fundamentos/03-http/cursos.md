# Cursos — HTTP

MDN es la fuente. No hay un curso de pago que merezca la pena solo para este módulo: el contrato se aprende leyendo transacciones reales.

## Gratuito

### MDN, HTTP

- https://developer.mozilla.org/es/docs/Web/HTTP
- Visión general, métodos, códigos de estado y cabeceras. Lee la visión general antes del ejercicio 1 y la página del método concreto cuando dudes si `PUT` o `POST`.
- La misma guía en inglés, si un término no coincide con el glosario: https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview

### Chuleta OWASP de CSRF

- https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html
- Léela al terminar el ejercicio 4, no para montar un ataque: para reconocer por qué una cookie no basta como prueba de que el formulario lo envió tu página. La defensa se practica en el ejercicio de PHP, no aquí.

## De pago

No compres un curso de HTTP para este repaso. Si más adelante quieres el protocolo por dentro (conexiones, TLS, cachés), el libro gratuito *High Performance Browser Networking* de Ilya Grigorik sigue siendo la lectura seria: https://hpbn.co/

## Qué dejar para más adelante

HTTP/2, HTTP/3 y diseño de cachés con `ETag`. No hacen falta para el contrato de la clínica.
