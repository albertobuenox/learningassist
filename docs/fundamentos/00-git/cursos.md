# Cursos — Git

No hagas un curso de ocho horas antes del ejercicio 1. El libro sirve para la duda concreta (“qué es el index”). El simulador sirve cuando llegues a las ramas.

## Gratuitos

### Pro Git

- https://git-scm.com/book/es/v2
- El libro oficial, en español, gratis. Capítulos 1 y 2 para el ejercicio 1. El capítulo de ramas, para el ejercicio 2. No lo leas entero el primer día.

### Learn Git Branching

- https://learngitbranching.js.org/
- Simulador visual. Haz los niveles de introducción y de mezcla cuando el ejercicio 2 te deje con la sensación de que las ramas son “otra carpeta”.

### GitHub Skills

- https://skills.github.com/
- Ejercicios cortos en un repositorio real de GitHub: primer commit, pull request, GitHub Actions más adelante. Úsalo en el ejercicio 3 si todavía no tienes un remoto.

## De pago

### The Git & Github Bootcamp (Colt Steele, Udemy)

- https://www.udemy.com/course/git-and-github-bootcamp/
- Recorrido largo, con calma, si Pro Git se te hace seco y quieres vídeo. No lo compres para el ejercicio 1: con el libro basta. Tiene sentido si vas a trabajar con ramas y pull requests todas las semanas.

## Qué dejar para más adelante

`rebase` interactivo, bisect y submódulos. Se aprenden el día que duelen, no como fundamento.
