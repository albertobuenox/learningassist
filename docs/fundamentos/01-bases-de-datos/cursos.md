# Cursos — bases de datos

Haz **uno** gratuito hasta el final y usa el resto como consulta. El de pago entra si quieres índices, planes de ejecución y diseño con más calma de la que dan los ejercicios.

## Gratuitos

### SQLBolt

- https://sqlbolt.com/
- Lecciones cortas con ejercicio al final. Sirve el primer día, para recuperar `SELECT`, `WHERE`, joins y agregados.
- No cubre diseño ni PostgreSQL en concreto. Una tarde.

### CS50 SQL (Harvard)

- https://cs50.harvard.edu/sql/
- Curso entero, gratis, con datasets reales: consultar, relacionar, diseñar, escribir, vistas, optimizar y una toma de contacto con PostgreSQL y MySQL.
- Es el mejor gratuito si quieres un arco completo. Varias semanas a ritmo de repaso, no de semestre.

### Relational Database (freeCodeCamp)

- https://www.freecodecamp.org/learn/relational-database/
- Proyectos con PostgreSQL, terminal y Bash. Encaja cuando ya haces un `SELECT` y quieres crear bases de verdad.
- Pide Docker o el entorno que indica freeCodeCamp. El certificado es gratuito.

### PostgreSQL Exercises

- https://pgexercises.com/
- Batería de preguntas sobre un solo dataset, de lo básico a ventanas y recursión.
- Úsalo como gimnasio después del ejercicio 3 de esta carpeta. Las soluciones del sitio existen: inténtalo antes de abrirlas.

### Documentación oficial, tutorial

- https://www.postgresql.org/docs/current/tutorial.html
- La referencia cuando un ejercicio hable de tipos, transacciones o `EXPLAIN`. No es un curso: es donde se comprueba una duda concreta.

### PostgreSQL Tutorial

- https://www.postgresqltutorial.com/
- Recetas ordenadas por tema (joins, constraints, índices). Buen complemento del manual cuando quieres un ejemplo mínimo.

### Select Star SQL

- https://selectstarsql.com/
- Libro interactivo breve, centrado en leer SQL con atención. Útil si escribes consultas que “casi” funcionan.

### Use The Index, Luke

- https://use-the-index-luke.com/
- Guía gratuita sobre índices, pensada para quien ya consulta bien y quiere que la consulta vaya rápida. Léela junto al ejercicio 6.

## De pago

### SQL and PostgreSQL: The Complete Developer's Guide (Stephen Grider, Udemy)

- https://www.udemy.com/course/sql-and-postgresql/
- Recorrido largo de SQL y de cómo PostgreSQL guarda y planifica. Actualizado en 2026.
- Cómpralo si el ejercicio de índices te deja con ganas de ver el motor por dentro. Udemy suele bajar de precio; no pagues el importe tachado sin mirar.

### Learning SQL (Alan Beaulieu, O'Reilly)

- Libro. PGExercises lo recomienda con razón: corto, claro, de lenguaje más que de un solo producto.
- Úsalo si prefieres leer a ver vídeo.

## Sitios de práctica extra

- SQLZoo: https://sqlzoo.net/ — otro gimnasio clásico, varios dialectos.
- Knight Lab, SQL Murder Mystery: https://mystery.knightlab.com/ — un caso para resolver solo con consultas. Hazlo cuando el ejercicio 3 te resulte fácil.

## Qué dejar para más adelante

Réplicas, particionado y almacenes analíticos. No hacen falta para recordar los fundamentos ni para el proyecto integrador.
